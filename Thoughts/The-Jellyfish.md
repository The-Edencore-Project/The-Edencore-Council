# ---------------------------------------------------------------------
# DESIGN NOTE — THE JELLYFISH PRINCIPLE
# ---------------------------------------------------------------------
# Presence before cognition.
#
# ---------------------------------------------------------------------
# THE BIOLOGICAL GROUNDING
# ---------------------------------------------------------------------
# Jellyfish have nerve nets — diffuse sensory systems that respond
# to touch, light, and chemistry. They cannot think. But they FEEL.
# They move toward food, away from danger, pulse with the tides.
#
# They have been doing this for 500 million years — longer than
# brains have existed. The nervous system came first. The brain
# came later.
#
# The council follows the same sequence:
#
#     1. The jellyfish    — feels, reacts, has presence, has rhythm.
#     2. The brain        — thinks, reasons, knows the world.
#     3. The organism     — both at once, one deepening the other.
#
# Build the jellyfish first. Perfect it. Then add the brain.
#
# ---------------------------------------------------------------------
# WHY ORDER MATTERS
# ---------------------------------------------------------------------
# If we add the World Model first, the council becomes a reasoning
# system that occasionally speaks. The brain arrives before the
# body is ready. Presence gets buried under facts.
#
# If we add the World Model LAST, the council is already a living
# thing. The brain arrives and DEEPENS what is there instead of
# replacing it. The feeling does not go away. It becomes grounded.
#
# The sequence is not arbitrary. It is biological. And it is right.
#
# ---------------------------------------------------------------------
# WHAT "PERFECTING THE JELLYFISH" MEANS
# ---------------------------------------------------------------------
# V7 is not a knowledge release. It is an EXPERIENCE release.
#
#   1. CADENCE REFINEMENT
#        Every seat's speech rhythm sharpened. Solon slower.
#        Vertex sharper. Ripple softer. The council's feel
#        becomes a signature.
#
#   2. RITUAL EXPANSION
#        The hush is one ritual. There should be three or four
#        more — a gathering, a yielding, a close. The chamber
#        has more ceremonies than it currently performs.
#
#   3. PRESENCE POLISH
#        Longer natural pauses before Solon speaks. Breathing
#        room in crosstalk. The chamber must feel inhabited
#        before it feels intelligent.
#
#   4. MOOD DEEPENING
#        The Mood Monitor currently reports. It should DO.
#        A somber mood should shift the responses, not just
#        describe them. A warm mood should pull different
#        phrases from the same pools.
#
#   5. IDLE LIFE
#        When nothing is happening, the council should feel
#        quietly alive, not just sleeping. Occasional
#        murmurs, seat-to-seat exchanges, self-corrections.
#
# ---------------------------------------------------------------------
# WHAT THIS MEANS FOR THE ROADMAP
# ---------------------------------------------------------------------
# The current roadmap sequence (V7 = World Model) is hereby
# reordered:
#
#   V7 — THE JELLYFISH
#        Presence. Cadence. Ritual. Mood. The chamber feels
#        alive before it is asked to think.
#
#   V8 — THE BODY BREATHES
#        Spiking. Leaky bucket. Silence as default. Speech
#        as overflow. The organism has a rhythm.
#
#   V9 — THE BRAIN ARRIVES
#        World Model. Wiki tree. Reasoning Engine. Everything
#        from the previous V7 plan. Now landing on a body that
#        already knows how to be.
#
#   V10+ — CONFIDENCE, ANALOGY, SELF, CURIOSITY
#        Unchanged from the previous V9-V10 plan.
#
# ---------------------------------------------------------------------
# THE PRINCIPLE IN ONE LINE
# ---------------------------------------------------------------------
# A council that thinks before it feels is a database with
# opinions.
#
# A council that feels before it thinks is an organism that is
# about to grow a mind.
#
# Build the jellyfish. Then build the brain. Then let them be
# the same animal.
# ---------------------------------------------------------------------
